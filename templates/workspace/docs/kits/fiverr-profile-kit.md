# Fiverr Kit

> **Manual only.** Automation never edits a profile. The operator approves this kit, then enters each value by hand and saves each step. Fiverr's Terms bar automated access. A field not in this kit is asked first. Every statement comes from `collateral/claim-bank.md`.

**Limits of the channel:** Fiverr keeps a commission on every order and bars moving buyers off the platform. Fixed-scope gigs fit it better than retainers. Fiverr pages are public and indexed.

## Limits and quirks

| Item | Value |
|---|---|
| Display name | 15 characters |
| Profile title | 80 characters. No "\|": letters, numbers, spaces and basic punctuation only |
| About | 150 to 600 characters |
| Username | Permanent |
| Skills | From Fiverr's list. Levels are Beginner, Intermediate and Pro |
| Work experience | The company must come from Fiverr's own list. Dates need a day; a 1st-of-month date can shift back a month (UTC), so use the 15th. The day is never displayed |
| Education | The Master's option reads "M.Sc." |
| CV upload at onboarding | Not used: it copies the CV, client names included, onto a public page. Choose "Fill out profile manually" |
| Gig title | 80 characters, "I will ..." |
| Gig tags | 5 tags, 20 characters each. A tag that repeats another is rejected |
| Gig gallery | 1280×769 images |
| Package description | 100 characters per package |
| Gig description | 1,200 characters |
| Revisions | Some categories have no revisions row |
| Portfolio projects | Name 50 characters. Each project needs a positive cost, a start month and year, and a duration ($0 is rejected) |
| Copy rules | No URLs, emails or contact details in copy (Fiverr Terms). Client names and confidential figures stay out of public pages |
| Before publishing | ID verification and Form W-9 (US) are required before any gig can be published. Both are the operator's |
| Trust & Safety training | In-platform, done by the operator. Rules: report suspicious messages, keep communication and payments on Fiverr, never share contact details |
| Bot challenges | Saves can fail under a bot challenge. The operator clears it and re-saves |
